Car Price Prediction with Machine Learning

Objective

Predict used car prices using machine learning techniques.

Dataset

Used Car Price Prediction Dataset from Kaggle.

Libraries Used

- Pandas
- NumPy
- Matplotlib
- Scikit-learn

Machine Learning Model

Random Forest Regressor

Steps Performed

1. Data Loading
2. Data Cleaning
3. Feature Encoding
4. Train-Test Split
5. Model Training
6. Prediction
7. Model Evaluation

Evaluation Metrics

- Mean Absolute Error (MAE)
- R² Score

Conclusion

The Random Forest Regression model predicts used car prices based on vehicle features such as mileage, fuel type, transmission, and manufacturing year. This project demonstrates a real-world application of machine learning in automobile price estimation.
